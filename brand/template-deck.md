## What is Claude Code?

- A way to **build real software** by talking in plain language
- It reads and writes files, runs commands, and *checks its own work*
- You stay in charge — you approve every step
- No terminal or GitHub knowledge assumed. We start from `zero`.

## Your turn: make it yours

1. Open the Code tab in the Claude app
2. Paste the starter prompt from `PROMPTS.md`
3. Change the headline to **your own name**
4. Ask Claude to change one colour

Done in ~10 minutes. Shout if you get stuck.

---

## Anatomy of a good prompt

```text
Build me a one-page personal site.
- Header with my name and a short tagline
- A section listing 3 projects
- A footer with an email signup
Use a warm, earthy colour scheme.
```

Be specific about **what**, let Claude handle the **how**.

---

<!-- _class: trap -->

## Don't paste secrets into a public repo

- API keys, passwords, and personal data **stay out of Git**
- Once pushed, it lives in history *forever* — even if you delete it
- Use a `.gitignore`; keep private files local

We set this up together on Day 1.
