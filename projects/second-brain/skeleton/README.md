# Second brain — skeleton (start here)

A docs-only starting point. You'll build *your own* second brain from the prompts —
you generate it, you don't copy it.

## How to use

1. Start Claude Code in this folder.
2. Read `PROMPTS.md` and answer the intake questions.
3. Point Claude Code at your source material (CV, notes, a website, product docs).
4. Let it build atomic notes into `vault/`, then organise and link them.
5. Ask it questions answerable *only* from the vault — that's the payoff.

## Stack

Plain markdown. `vault/` holds **one example note** to show the shape — replace it
with your own. Optionally open this folder in **Obsidian** for a nicer UI.

> This becomes the context for **Build 3** (your chat agent). A job-seeker's brain
> is their career; an entrepreneur's brain is their product.
