# CLAUDE.md — second brain (repo-local guidance)

This folder is a **second brain**: a vault of markdown notes about a single
subject (the learner — for a job hunt — or their product, for customers).

When working here:

- Keep all notes in `vault/`, **one idea per file**, with a clear title.
- Make notes **atomic and linked** — use `[[wikilinks]]` between related notes.
- Maintain a `vault/index.md` that lists and groups the notes.
- When asked a question, **answer using only what's in the vault.** If something
  isn't there, say so plainly — never invent facts.
- Keep source documents (CV, exports) out of `vault/`; the vault holds the
  distilled notes, not raw dumps.

This vault is the **context** a later chat agent (Build 3) will answer from, so
clarity and accuracy here matter more than volume.
