# Example note (delete me)

This is what an **atomic note** looks like: one idea, a clear title, and links to
related notes.

For a job-seeker's brain a note might be a single project:

> **Led the checkout rebuild** — Cut checkout load time from 4s to 0.9s by
> rebuilding the flow; conversion rose ~12%. See also [[Skills — frontend]].

For an entrepreneur's brain a note might be a single product fact:

> **Refund policy** — 30-day no-questions refund. See also [[FAQ]].

Replace this file with your own notes. Keep one idea per file and link them with
`[[double brackets]]`.
