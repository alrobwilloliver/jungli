# Agentic Second Brain — one-hour class

Build with Sam's fictional Markdown vault, then optionally connect your own
notes. Start in [`skeleton`](skeleton/README.md); the instructor reference is
[`finished`](finished/README.md). Read [`MODEL-SETUP.md`](MODEL-SETUP.md) before
class and use [`INSTRUCTOR-GUIDE.md`](INSTRUCTOR-GUIDE.md) while teaching.
Record timings in [`REHEARSAL.md`](REHEARSAL.md).

The class upgrades a working all-context chatbot into a bounded agent with
`list_notes`, `search_notes`, and `read_note`. Sam's vault is the complete core
success. Personal notes are an optional final step with an explicit privacy
gate.

The [embeddings extra](extra-extra-embeddings/README.md) is outside the
60-minute core. Earlier builds: [Second Brain](../second-brain/README.md) and
[Chat Agent](../chat-agent/README.md).
