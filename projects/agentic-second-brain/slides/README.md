# Agentic Second Brain slides

[`agentic-second-brain.pptx`](agentic-second-brain.pptx) is the editable
learner-facing deck for the one-hour optional workshop. It follows the same
sequence as the four prompts in
[`../skeleton/PROMPTS.md`](../skeleton/PROMPTS.md):

1. distinguish the all-context baseline from an agent;
2. introduce `list_notes`, `search_notes`, and `read_note`;
3. connect the bounded controller;
4. verify a search → read → cited-answer trace.

The final slides cover adapting an existing API route and explain why embeddings
remain an optional extra-extra.
