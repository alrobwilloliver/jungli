# Teaching Pack — AI & Agents Track

The **slide-ready** version of the course: every lesson broken into talking
points, resources, a practical task, questions, and base prompts. Built to turn
straight into PowerPoints + student handouts.

- **One file per day** (`day-1.md` … `day-5.md`). Each file = one teaching day ≈
  **2 hours** of structured time. Make **one deck per day**, or split each lesson
  into its own deck — the lessons are clearly delimited either way.
- Pairs with [`../lesson-plans.md`](../lesson-plans.md) (the timed facilitation
  script) and the build projects in [`../../projects`](../../projects).

## How each lesson is laid out

| Field | What it's for |
|---|---|
| **Talking points** | Your slide bullets — the concepts to land, in order. |
| **Resources** | Links, tools, and project files to have open. |
| **Practical task** | What students *do* after your instruction (often in their own/open time). |
| **Questions** | Short comprehension/application questions to set after the task. |
| **Base prompts** | Copy-paste prompts students use. Many come straight from each build's `skeleton/PROMPTS.md`. |

## The week at a glance (~2h structured/day + open build time)

| Day | Focus | Lessons | Build |
|---|---|---|---|
| **1** | Ship a live site | 1.1 agent + the loop · 1.2 build your landing page · 1.3 save it & put it live | Build 1 |
| **2** | Drive the agent + second brain | 2.1 tokens & context · 2.2 brief/plan/debug · 2.3 second brain · 2.4 models & limits | Build 2 |
| **3** | Build a chat agent | 3.1 what an app is · 3.2 build the chat · 3.3 API keys & secrets · 3.4 fit-assessment + deploy | Build 3 |
| **4** | Agent powers + start your own | 4.1 skills/superpowers · 4.2 MCP · 4.3 scope your project | begin own |
| **5** | Ship, plan your next, demo | 5.1 planning a project · 5.2 demos & peer testing · 5.3 territory map + keep going | demo + plan |

**Time model:** your ~2h/day is the *structured lesson*. The actual building
spills into students' own time and the open weekend hours (lightly mentored) — so
the personal project is **scoped on Day 4, built in open time, and Day 5 teaches
the repeatable planning method** so they can keep going after the residency.
