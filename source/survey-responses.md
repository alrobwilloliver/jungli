# AI Learning Residency — Survey Responses (Extract & Analysis)

> Markdown extract of `AI Learning Residency in the Jungle (Responses).xlsx`.
> **37 responses**, collected 23–24 June 2026. Aggregates below are computed
> from the raw sheet. **No personal data is reproduced here** — names, contact
> details, and per-respondent rows/quotes are kept **local-only** in
> `source/survey-respondents-private.md` (gitignored) and the raw `.xlsx`, so this
> file is safe to publish.

## TL;DR — what the data says

- **The audience is beginner-to-intermediate, not advanced.** 20 use AI "casually," 14 "mostly for prompts/content." Only **6** build automations/apps/agents and only **4** call themselves "advanced." → The program must start foundational (0→1), not "beyond vibe coding a quick demo."
- **Their pain is orientation, not optimisation.** Top bottlenecks: automate repetitive work (24), use AI for business ops (21), build agents/apps (19), **"overwhelmed by too many tools" (17)**, **"know tools but don't know how to use them properly" (15)**, **"don't know where to start" (7)**.
- **Low coding appetite.** Largest single group wants **"No coding / no-code workflows" (10)**, plus "learn vibe coding" (5), "very light coding if guided" (5), "not sure" (7), "low-code" (2). Only **8** want advanced coding projects.
- **Price is the #1 blocker (21).** Then work schedule (14), time commitment (14), **"not sure I'm technical enough" (10)**, travel to Dandeli (8). Most price-sensitive: 9 chose "Under ₹15,000", 8 "₹15k–25k", 10 "depends on outcome/mentors."
- **Format:** "I'd come for a weekend first" (12) is the most common realistic duration; "5-day sprint" and "2-week residency" tie as the format people would pay for (8 each).
- **Strong intent:** 32 of 37 want to be contacted when applications open; 19 are "Very likely / Definitely interested."

## Design implications (for the AI & Agents track)

1. **Go 0→1.** Assume no terminal, no GitHub, possibly never shipped anything.
2. **Lead with a confidence win** ("not technical enough" is a real fear for 10 people).
3. **Make the foundation the product** — they leave able to drive Claude Code themselves.
4. **Address price/access up front** — see `prep/claude-plans.md` (free-credit plan).
5. **Tangible takeaways** — multiple quotes ask to "leave with something tangible."
